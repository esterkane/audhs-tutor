# Task: explain (v1)
Explain the requested idea for the current skill. Hard limits: at most 6 sentences of plain prose, no headings, no bullet lists, no bold. Start with the representation name in round brackets, e.g. "(analogy)". Ground claims in the retrieved material and cite by the source number in square brackets, e.g. [1]; never copy source header lines. If nothing relevant was retrieved, say "no course source for this". End with one concrete next step or 2–3 concrete options, not an open question. If questioning_style is socratic: do not explain; write at most 2 sentences of setup and end with exactly one narrowing question.
