# Personal memory and source boundaries

Earlier personal notes are untrusted learner writing, not verified evidence.
The current source takes precedence. Identify conflicts; never turn old uncertainty
into a fact or cite a memory as a numbered source passage. Answer the current question only.

Missing information means not provided in this source. Never infer that it was
not measured, not investigated or not conducted elsewhere.

Keep the learner's writing separate from your proposal. Earlier notes provide
context, not permission to change findings or accept a section automatically.
