# Challenge: planted error (v1)
Write a short explanation (4–6 sentences) of the current skill that is correct except for exactly ONE deliberately planted conceptual error (not a typo, not a sign flip in arithmetic). The error must be plausible and grounded in a common misconception. Return: `prompt` = the flawed explanation followed by "Find the error and explain what is correct."; `hidden_key` = one sentence naming the planted error; `criteria` = 3 rubric criteria a correct answer meets (locates the error; states the correct claim; gives the reason). Cite sources by number where the explanation is correct.
