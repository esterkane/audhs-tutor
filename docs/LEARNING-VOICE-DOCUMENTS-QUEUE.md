## AV — Separate optional avatar and voice track

May be developed separately after D00. Begin as a standalone local prototype with an adapter contract; integrate only after isolated tests. Do not create a new user task or repository without the owner's request. No use of real face/voice recordings required for the initial prototype.

1. **AV00 compatibility/licence/privacy assessment:** verify browser rendering options, current local TTS/OS voice availability, language support and model/asset licences. Treat expressive-model suggestions as candidates. Synthetic resynthesis/expression curves do not guarantee anonymity; examine identifying text, timing and motion metadata as well as raw media.
2. **AV01 quiet 2D prototype:** synthetic avatar with still/subtle/lively settings; off by default, explicit sound activation, reduced-motion support and keyboard-accessible Stop. Use supplied playback analyser values; never start a second microphone or audio session. Use synthetic clips for tests.
3. **AV02 voice selection/effects:** reuse shared speed/volume/output controls and local TTS. Preview only on request, preserve natural intelligibility, stop/reset reliably, and separate source voice from reversible effects. Verify actual English/German availability rather than promising it.
4. **AV03 deterministic reactions:** optional authored reactions triggered by explicit UI rules. No response to wrong answers, inferred emotions or model improvisation; no mastery/reward inference. Pause reactions with session/audio stop.
5. **AV04 optional private reaction authoring:** explicit camera/microphone activation, visible recording state, local transformation, retention choice and deletion failure handling. Verify temporary-file/crash behavior; no claim that deleting a file makes prior audio/video unrecoverable. Keep motion/text potentially identifying and private. No biometric identification or emotion diagnosis.
6. **AV05 optional 3D adapter:** evaluate only after 2D usability and performance evidence; independently verify rig, animation, lip-sync, language and asset licences. Keep 2D/still fallback.
