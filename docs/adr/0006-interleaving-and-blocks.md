# 0006 — Interleaving policy and cross-domain blocks
Date: 2026-09-19
Status: Accepted
## Context
Evidence supports within-domain interleaving of confusable concepts; cross-domain interleaving (AI + guitar + language) is not shown to boost retention and can cost attention residue; AuDHD monotropism argues for flow protection.
## Decision
Interleave confusable AI/ML concepts inside review blocks. Language, guitar and movement are whole blocks scheduled at block boundaries for spacing and engagement; the planner never switches mid-concept and requires a minimal grasp check before an early switch. Movement precedes new material or follows it immediately, never during.
## Consequences
+ Engagement and spacing without shallow switching. − The n-of-1 engine should test block lengths per mode.
## Alternatives considered
Frequent micro-switching (rejected).
