# Local group-count comparison

The local model evaluations exposed unreliable subtraction, denominators and attribution in cleaning feedback. This optional calculator takes explicit learner-entered counts instead of extracting or inventing them from prose. It is available under Compare group counts locally in the notebook/project tutor.

For each named group, enter before and after counts in the same unit. Compare counts computes removals, retention/removal rates, shares within the entered groups and percentage-point changes. Ratios expose their denominators; displayed percentages are rounded. Zero denominators are undefined, never silently zero. The view assumes nonoverlapping comparable groups and after counts no larger than before counts; it does not assess fairness, source validity, execution or mastery.

All calculations stay in the browser and require an explicit click. Editing inputs removes the old result until recalculated. Versioned drafts are saved for the current session and study target in this browser; storage failure preserves the current entries with a visible warning. Numbers are not automatically inserted into a tutor request or sent to a model. This is a numerical aid, not a replacement for Check my answer or a dataset import/parser.
