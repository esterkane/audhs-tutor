# Slice: vocab-identity (P3, 2026-09-20)

**Story.** A vocabulary card was identified by `language:word`, so "Bank (bench)" and "Bank (financial)" collapsed into one card and a re-add silently kept the first meaning (review caveat). A card is now identified by **language + direction + normalised word + normalised meaning**; existing cards keep their ids and FSRS history.
**In/out.** `kernel/practice.py`: `norm_text` (whitespace-collapsed casefold), `vocab_ref(lang, direction, word, meaning)`, `legacy_vocab_ref`; `add_vocab(..., direction="forward"|"reverse", attribution=None, commit=True) → (item, created)`. **Update policy:** same identity → the existing card is returned untouched (schedule preserved) except that a missing `example` or source attribution is filled in; a different meaning → a new card; a card still carrying the legacy ref is *adopted* under the new identity when its stored meaning matches (ref rewritten, schedule kept). Reverse cards (`translation → word`) exist only when asked for (`direction="reverse"`, or the import's "also reverse" option). Migration `p3 vocab card identity …` (data-only) rewrites legacy refs from the stored question/answer; `make migrate-check` verified it on a copy of the dev DB (0 vocab cards in the owner's DB today). `memory.ensure_item(commit=False)` for atomic bulk imports.
**Events.** None; the card rows are the durable record. Reviews keep emitting `reviewed` with `item_type=vocab`.
**Mode/energy.** Unchanged — cards only ever appear in the language block.
**Verified by.** `tests/test_vocab_import.py`: two meanings → two cards; whitespace/case variants → one; re-adding after a review keeps the FSRS stability and item id; legacy ref adopted; reverse card only when selected; migration on a disposable DB.
**Review fixes (2026-09-20).** NFC + `lower()` identity (not `casefold()`), percent-escaped parts, legacy detection by the missing `direction`, `DeckIndex` for O(1) lookups, `vocab_deck(commit=…)`; inactive cards are ignored when matching (a deactivated card can be re-added).
