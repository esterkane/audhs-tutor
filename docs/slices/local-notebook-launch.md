# Local notebook launch from the app

User prepares a full local notebook from the notebook panel; app copies an explicitly configured private bundle without overwriting edits, starts token-authenticated loopback Jupyter, polls setup status, and offers the authenticated notebook link. Missing environment offers an explicit install action using the same pinned packages as the existing CLI. No notebook execution, model calls, learning evidence or official progress updates. Course-specific packages remain explicit. Native Python file access is disclosed; tokens are not logged or persisted in browser storage. Files stay under ignored data/notebooks, private source bundles under local-learning. App shutdown stops only the lab process it owns. Keyboard buttons, status/errors and typed fallback remain; no audio/motion is started.
