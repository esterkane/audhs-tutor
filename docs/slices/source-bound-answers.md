# Source-bound answers

The local tutor can reuse measured transaction-isolation retry results without asking a model to
paraphrase their numbers or decisions. This extends reviewed local reuse; it does not change provider
routing, session storage, learning modes or hosted spending controls.

## Evidence and assembly

The generic kernel captures immutable canonical JSON with a revision hash. Host-authored bindings
select scalar fields and registered comparisons; answer plans contain only allowed fact identifiers.
The assembler requires every contracted slot, rejects stale revisions and cannot substitute a successful
commit for a false business predicate. Unverified learner and tutor statements can only be attributed
text quotations. Accepted material remains subject to the caller's authorization and factual review.

The saved-lab adapter accepts only complete, successful named tool call/result pairs from the current
session. It checks ordering, unique IDs, matching strict inputs, the five independent trial schedules,
retry provenance, decisions, committed changes and fixture cleanup. It distinguishes a recorded null
read from a missing observation. Invalid or ambiguous records do not become evidence.

For explicit neutral-mode requests, a conservative English/German reference resolver selects existing
experiments. A closed report presents original versus fresh counts, count > minimum, updates before
commit, commit outcome and the separate final active >= minimum rule. No SQL or model call occurs.
Source identifiers and revisions are visible in the answer. Every original message remains stored;
only a new learner question and complete answer are appended.

## Scope and fallback

This is a qualified view of saved measurements, not a general natural-language semantic verifier.
Unknown vocabulary, ambiguous references, mixed requests, new experiments, active incidents/labs and
Socratic/exam modes retain the original complete tutor path with the unchanged history and request.
It does not summarize or truncate session history, fix arbitrary causal generation, establish the
world-truth of accepted material, or activate unpublished context-compression experiments.

## Verification

Kernel, provenance, rendering, reference selection and orchestrator tests cover incorrect comparison
operators, missing coverage, changed sources, false versus null, duplicate/reordered tool results,
conflicting source qualifiers, unsupported mixed requests and unchanged original histories.
Browser coverage exercises real disposable experiments, English/German saved-result follow-ups,
keyboard/mobile accessibility, unsent drafts and exact reload/resume. The existing incident/reference
and source-to-authoring workflows remain regression gates. Synthetic unit fixtures and isolated learner
data are used; private sessions and acquired content are excluded from publication.
