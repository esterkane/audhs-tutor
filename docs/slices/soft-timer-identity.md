# Slice: soft-timer-identity (P1, 2026-09-20)

**Story.** The wind-down prompt belongs to a block, not to a component instance: it is derived from the server's `block_started_at` + `planned_min` + the extensions the learner asked for. A new block, a reload or an accepted re-plan never inherits an expired deadline (review finding 3).
**In/out.** `SoftTimer` props: `blockKey`, `startedAt`, `plannedMin`, `extensionMin`, `onExtend`; mounted with `key={block_id}`. "+5 minutes" → `POST /api/plan/blocks/extend` → `timer_extension_min` in `BlockState` (kept across reloads); "Finish this block" → `advance`; "Save & stop" → `end(save_and_stop)`. Documented behaviour: **pause** does not exist (a soft timer never blocks anything; leaving the tab keeps the clock running and a late return shows the prompt once); **+5** moves the deadline and hides the prompt until it is reached again; **accepted re-plan** changes `planned_min` of the current block → the deadline moves accordingly, the block's start time is kept; a new block resets extensions to 0.
**Events.** None (the prompt is UI; ends and extensions are visible through `block_ended.actual_min`).
**Mode/energy.** `planned_min` already encodes mode/energy; the fallback `SOFT_TIMER_MIN[mode]` applies only when a block has no planned minutes.
**Accessibility.** `role=status` card, three literal options, optional browser notification behind `ui.notifications`; no sound, no motion.
**Verified by.** `Session.test.tsx` (30-minute-old start on a 5-minute block shows the prompt; "+5" posts the extension) and `test_session_transitions.py::test_timer_extension_and_tutor_turn_keep_block_state`.
**Review fixes (2026-09-20).** `+5 minutes` goes through the one-in-flight dedupe and all three buttons are disabled while a transition is pending (no `+10` on a double-click); extensions are recorded on `block_ended.result.timer_extension_min` so the adaptation observer can see "keeps extending new material" after the checkpoint is gone; `SoftTimer.test.tsx` covers hide-on-extension and a fresh block key.
