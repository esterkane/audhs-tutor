# Slice: experiments (Stage 4)

**Story.** I can run an n-of-1 experiment on myself — Socratic vs explicit on matched skills, worked-example-first vs problem-first, short vs long blocks — start it, stop it, and read the outcome from my own event log as a hypothesis with the raw numbers, never as a hidden score (ADR-0005 step 3 groundwork, ARCHITECTURE §8).
**In/out.** `kernel/experiments.py`: three templates (`TEMPLATES`), `create()/from_template()/start()/stop()` (one running experiment per unit type), balanced deterministic assignment per unit (`assign()`: fewest-units arm, hash tie-break, idempotent, `assigned` event with the arm stamped in `experiment_arm`), `arm_for_node()` (node-unit: the tutor turn resolves the node's arm and applies `socratic` / `representation` from the arm config, stamps every event and the turn meta) and `arm_for_session()` (session-unit: applied at session start, `session.experiment_arm_id`, disclosed in `SessionOut.experiment`), `outcomes()` (metrics read from events per arm: delayed recall = share of reviews rated ≥ Good, error rate, latency, block completion, voluntary continuation = sessions longer than planned, transfer = evidence on the transfer dimension), `results()` (per-arm n/mean/sd, difference, 95 % CI from the standard error, literal reading; `record=True` persists `experiment_observation` rows + `measured` events). Schema: `experiment.{unit_type, started_at, ended_at}`, `experiment_assignment`, `session.experiment_arm_id` (migration `e2adb21ba4ae`). API `/api/experiments` (list with templates + metrics, create, from-template, start, stop, results with per-unit assignments). UI `/experiments`: list, Start/Stop, Results dashboard (metrics as hypotheses with n, mean, difference, CI, reading; assignments; "never as a score of you"), create from template. Session screen banner names the running experiment and arm.
**Events.** `assigned` (result arm/metric/n, context experiment_id), `measured` (per metric per arm on a recorded read); all events of a session/turn carry `experiment_arm`.
**Mode/energy.** Arms never change mode or energy; a session-unit arm may set `socratic` (disclosed), a node-unit arm sets the questioning style per node (disclosed on the session screen).
**Accessibility.** Text and lists only; metrics list labelled.
**Verified by.** `tests/test_experiments.py`: template lifecycle, balanced sticky assignment (3/3 over six nodes), one running experiment per unit type, stop ends assignment; outcomes from synthetic events per arm with a supported-hypothesis reading and observation rows; session-unit arm applies `socratic` and is disclosed on `SessionOut`; node-unit arm stamps `experiment_arm` on the `explained` event of a real turn; voluntary continuation from session lengths. `Experiments.test.tsx`. Stage 4 benchmark B simulates a two-week Socratic-vs-explicit run.
**Open.** Only one experiment per unit type runs at a time; CIs assume roughly normal means (fine as a reading aid at n < 30, not as proof); a contextual bandit (ADR-0005 step 3 proper) is not built.
**Review fixes.** Arm representations go through `representations.allowed_kinds(mastery)` (problem-first only at mastery ≥ 0.6; otherwise the turn meta says `arm_not_applied`); session-unit arms are assigned *before* planning so `new_material_min` arms really change block lengths (`build_plan(overrides=…)`); the outcome window keeps `reviewed`/`evidenced` events after Stop (that *is* the delayed outcome) and only loads the four outcome verbs; CIs use t critical values (small-n honest), "Hypothesis supported" needs the primary metric and n ≥ 10 per arm, otherwise "Difference favours … a reading aid, not proof"; `voluntary_continuation` is directionless; `(experiment_id, unit_id)` is unique (migration `5e3a8f8d231b`, race-safe re-read); sessions with no plan are skipped for continuation. Vocabulary cards are FSRS ratings, not graded feedback: no confidence step (documented exemption).
