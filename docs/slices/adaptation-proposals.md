# Slice: adaptation-proposals (Stage 4)

**Story.** The system notices a pattern in my own event log and *asks* before changing anything: a card with the observed numbers and four literal choices — Try it this session / Make it the default / No / Don't suggest this again. Whatever I accept is logged and undoable in one click (ADR-0003, ADR-0006, AuDHD invariant "no covert adaptation").
**In/out.** `kernel/adaptation.py`: five deterministic rules over `learning_event` / `session` / `memory_state` (`hint_heavy` → worked-example-first, `early_exit` → shorter new-material blocks, `movement_skipped` → movement off, `review_backlog` → longer review block, `low_energy_sessions` → Low-capacity preselected); `observe()` creates one open card per pattern, `propose()` lets the planner raise a card, `decide()` applies through the preference registry with origin `proposed_accepted` (Try = scoped to the session, reverted by `expire_trials()` at the next session start), `undo()` restores the stored previous value, `history()` is the log. Re-ask policy: open or `never` → blocked; `no` → blocked 14 days; `default` in effect → blocked until undone. Schema: `adaptation.{pattern, apply_json, previous_json, evidence_json, session_id}` (migration `064e2993cba7`). API `/api/adaptations` (`GET` open cards, `POST /observe`, `POST /{id}/decide`, `POST /{id}/undo`, `GET /log`); session start runs `expire_trials` + `observe`. UI: `AdaptationCards` on Home (four buttons, the why, the exact preference and value), `AdaptationLog` with Undo under Preferences; hooks in `features/adaptations/api.ts` (`useAdaptationLog`).
**Events.** `proposed` (context what/why/origin), `decided` (result decision), `adapted` (via `set_pref`, origin ≠ explicit), `undone` (why = "undone by the learner" | "trial session ended"). Policy version `adapt.v1`.
**Mode/energy.** Cards never auto-apply and never change the current session's mode. Low-energy pattern proposes a Home preselection only.
**Accessibility.** Cards are plain buttons with titles explaining each choice; the log is a list; no motion.
**Verified by.** `tests/test_adaptation.py`: no card without evidence; hint-heavy card with the numbers in the why; no duplicate open cards; Try applies with origin `proposed_accepted` and expires at the next session (undone event "trial session ended"); default → in effect → not re-proposed → undo restores; never silences; no blocks 14 days then re-asks; early-exit / low-energy / backlog rules from synthetic events and due items; planner `propose()` dedupe + full route round trip. `AdaptationCards.test.tsx` (four choices, Try posts session id; log offers Undo only for changes in effect).
**Review fixes (pedagogy + code reviewers, same day).** Card targets are now consumed: `tutor.representation_default` is applied by the tutor turn for skills below mastery 0.6 (never above — expertise reversal), `session.default_mode` preselects the mode on Home (with a note). Rules: `hint_heavy` needs ≥ 2.5 hints/attempt on unmastered skills; `early_exit` ignores `save_and_stop` and `skipped` (honouring the soft timer is not an early exit); `review_backlog` counts AI/ML cards only; `low_energy_sessions` wording "ran at". State machine: Try needs a running session (refused otherwise; hidden in the UI), an in-effect trial blocks a second card on the same pattern, `previous_json.was_set` makes undo reset to the default when nothing was set before, plan cards cannot be made "the default", `adapted` events carry the adaptation id + `adapt.v1`. Trials expire *before* the next session is planned. Try hint says "you may be asked again". Session screen shows planner cards only; observed-pattern cards stay on Home.
