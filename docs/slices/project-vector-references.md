# Retrieve maintainer evidence for vector operators

The indexed pgvector maintainer README can now participate in the project tutor's reserved operator references. Previously this lookup selected only Supabase guides, and repeated searches could omit the indexed explanation of negative inner product and ascending operator index scans.

The lookup accepts only the pgvector repository README on master or a numeric release tag. It retains active-source and product filters, exact retrieved content, source identity, bounded result count and citation validation. Among passages matching the same number of requested operators, maintainer documentation is preferred. It does not fetch documents, change model routing, create course material, or modify session history. Source versions remain visible; this is not automatic compatibility validation for the installed extension.
