# Preserve explanations during citation placement

When the only blocking finding is missing citation attribution, a hosted project tutor can now return source-number placements instead of regenerating its complete explanation. The host identifies exact plain-prose paragraphs, restricts references to the existing source-bound citation catalogue, and inserts markers without rewriting other bytes or metadata. All output guards run again.

Unknown or repeated references, incomplete plans, changed source context, unsupported claims and failing guards cannot complete this path. A declined/invalid placement falls back once to the existing full repair, using the original history and repair request. Complex Markdown and other blocking findings keep the full repair. Local generation is unchanged. Budget authorization and attempt accounting still use the gateway.

This validates attribution structure, not factual entailment. The hosted model is instructed to decline when the retrieved evidence does not support a target. A correctly formatted citation does not prove a claim true; broader factual accuracy remains unfinished.

Validation: 409 host Supabase tests; 234 native tests with 47 service-dependent skips; Ruff, format and mypy pass. A natural hosted browser run passed without requiring repair. Two labelled fault-injection browser workflows exercised citation repair with experimental Responses and the deployed Chat Completions adapters; both passed source checks, no-quiz behavior, full transcript resume and budget refusal. Exact persisted-answer comparisons showed only marker insertions and unchanged metadata. Repair calls measured 3.317 and 3.566 seconds; earlier full-answer citation rewrites measured 9.470 and 9.053 seconds. These are bounded observations, not a guaranteed latency reduction or decoding benchmark. The deployed model still missed an unstated caller-privilege qualification in its original explanation; placement preserved that text and does not claim to fix it. Model routing is unchanged.
