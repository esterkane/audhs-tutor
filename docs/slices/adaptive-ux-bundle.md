# Slice: adaptive-ux-bundle — energy-planner, body-doubling, sensory-settings, models-settings-screen, parking-lot-promote, soft-timers (Stage 4)

**Story.** The session bends to my state without ever deciding for me: an energy check-in re-plans the rest as a card; a presence screen keeps me company without tracking; sensory settings are mine; the model registry is a screen, not a CLI; parked tangents have two literal next steps; timers only ever ask.
**In/out.**
- *energy-planner*: `planner.replan(plan, from_index, energy)` keeps past blocks, re-scales the rest, drops optional/challenge blocks at energy 1, always ends with recap. `POST /api/plan/replan {session_id, energy, from_index}` records the learner's energy on the session (their statement, not an adaptation) and raises a planner card (`pref="session.plan"`) whose Try/Default replaces `session.planned_blocks_json` and whose Undo restores it. Session screen: "Energy now" 1–5 + `AdaptationCards`.
- *body-doubling*: `/together` — the one current task, minutes-here (soft), "Back to the session"; brown noise generated in-browser, only when `ui.ambient` allows and only on a click; no events, no timers.
- *sensory-settings*: preferences `ui.theme` (system/light/dark), `ui.font_scale`, `ui.notifications`, `ui.ambient` (+ existing `ui.reduced_motion`, `ui.density`, `ui.sound`); `useSensory()` applies `data-theme` / `data-density` / `data-font` / `.reduce-motion` on `<html>`; `prefers-reduced-motion` is always honoured; dark tokens in `index.css`.
- *models-settings-screen*: `models_ai/manage.py` (seed, search HF, add, pull, bench, assign, remove, routing table — shared with `scripts/models.py`, which now delegates), `api/models_admin.py` (`GET /api/models`, `/search`, `POST /`, `/{id}/pull` and `/{id}/bench` as background jobs with progress lines in `GET /jobs`, `/{id}/assign`, `DELETE /{id}`, `GET /routing`), `/models` screen: registry table (status, size, licence, benchmark), Download/Bench/Remove per row, jobs list, routing table with per-task override select (ready + benchmarked only), Hugging Face search + add form.
- *parking-lot-promote*: `POST /api/parking/{id}/promote {promoted_to: next_session | node_id}` (event `promoted`), `POST /{id}/drop`; the dialog lists parked items with "Promote to next session" / "Drop"; Home shows promoted items until "Done".
- *soft-timers*: the existing wind-down prompt (Save & stop / 5 more minutes / Finish this block) gains an optional browser notification behind `ui.notifications` (permission requested when the preference is switched on). Never a cut-off.
**Events.** `proposed`/`decided`/`adapted`/`undone` for re-plans; `promoted` for parking; model jobs are not learner events (registry status is the record).
**Mode/energy.** The check-in changes `session.energy` immediately (explicit) and the plan only through a card.
**Accessibility.** Energy buttons are a labelled `role=group` with `aria-pressed`; tables have column scopes; Together has no motion; ambient audio never autoplays.
**Verified by.** `tests/test_stage4_bundle.py` (replan invariants, check-in → card → apply → undo, no card when nothing changes, promote/drop + 404s, sensory prefs, models API incl. background pull job failing visibly without an API key, 404/400/409 paths). Frontend: `Models.test.tsx` (download only on click, routing), `Together.test.tsx` (no sound without the preference), parking test updated for the list. Live: `/models` shows the real registry (reranker 81.6 ms / 16 docs), `/together` shows the running session's node.
**Open.** HF search needs network; bench of a hosted model needs an API key; the jobs list lives in process memory (restart clears it, registry status stays).
**Review fixes.** `Block.base_min` records the energy-3 length so re-planning 3→1→3 returns the original minutes (no un-scaling guesswork); `from_index` bounded; accepting a plan card refreshes the session query; dropped parking items cannot be promoted; the models jobs list is pruned and only polled while a job runs; ambient sound stops when the preference is switched off; practice rating anchors without evaluative words ("could not do it" … "did all of it").
