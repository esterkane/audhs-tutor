# Slice: code-exercise (P8, 2026-09-20)

**Verified first.** No runnable code flow existed: `@codemirror/state`/`@codemirror/view` were declared but unused; Pyodide was not in `package.json`; no `code` assessment kind, no exercise route. ADR-0008 fixes the execution model: learner/model code runs only in Pyodide (browser) or a limited sandbox — never on the backend host.
**Story.** On a skill that has one (first: *Scaled dot-product attention* → `attn-scaled`), the learner opens the optional code exercise, reads prompt + explicit success criteria + source citations, edits starter code, **runs** it in the browser sandbox, sees the deterministic checks, asks for hints one at a time, and — separately — **submits** an attempt after rating confidence. Application evidence lands on the node through the ordinary grader and a follow-up item is scheduled ≥ 2 days out. The full solution is an explicit two-click action, logged, followed by a check question.
**Execution model + policy (decision).** Pyodide `v0.27.8` **from jsDelivr** in a classic Web Worker (`features/code/pyodide.worker.js`): no npm dependency, the runtime + `numpy` are fetched once (browser cache). After the load, `fetch`/`importScripts` are replaced and `XMLHttpRequest`/`WebSocket`/`EventSource`/`Worker`/`caches`/`indexedDB` removed **on the worker global and its prototype, frozen** — a best-effort lockdown; the real boundary is the browser's worker sandbox (no host files, no backend execution), and the policy text says exactly that; the filesystem is Pyodide's in-memory one, discarded when the worker stops (ADR-0008 says "read-only" — an in-memory scratch FS is the honest description; owner may amend the ADR wording); the main thread enforces the timeout (10 s) by **terminating** the worker (the only way to stop a busy WebAssembly thread) and recreating it on the next run; stdout/stderr are capped in the worker (20 000 chars, `truncated` flag). The policy is shown to the learner ("Where your code runs"). Editor: an accessible `<textarea>` (Tab → two spaces); CodeMirror needs `@codemirror/lang-python` + `@codemirror/commands` for a real editor — **owner decision** recorded in `docs/IMPROVEMENT-PLAN.md`; the two declared packages stay unused for now.
