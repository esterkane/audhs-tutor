# Slice: seed-attention (Stage 1)

**Story.** The learner opens the app and finds a real curriculum: 8 attention skills with prerequisites, one LearningObject each, 18 assessments (MCQ, cloze, explain-back with rubrics) and 14 grounded chunks from two sources, retrievable with citations.
**In/out.** `seeds/attention/skills.yaml` (nodes: dot product → softmax → dot-product attention → scaled → multi-head / masking → KV cache; positional encoding), `seeds/attention/sources/*.md` (study notes + Vaswani 2017 section summaries, front matter with course/trust/uri, `## heading {skill: slug}` tags). `kernel/seed.py::load_seed` (idempotent by slug / seed_key / content hash), `knowledge/ingest/markdown.py` (front matter + section chunker), `knowledge/ingest/service.py` (document → version → chunk → provenance), `knowledge/reindex.py` (latest version per document → Qdrant, updates `index_state`). `scripts/seed_attention.py [--no-index]`.
**Kernel added here.** `kernel/skill_graph.py` (topological order, prerequisites, unlock gate at mastery ≥ 0.6, Stage-1 `next_skill` rule), `kernel/competency.py` (evidence rows → decayed weighted view, coverage-aware mastery over the node's required dimensions), `kernel/memory.py` (FSRS cards, due queue, review cap by mode/energy, `now` injectable), `kernel/session.py` (start/end/checkpoint, `EventContext`), `kernel/learner.py` (owner profile).
**Events.** `evidenced` (competency), `reviewed` (memory), `started`/`ended` (session). No LLM calls.
**Verified by.** `tests/test_kernel.py` (parser, idempotent seed, chunk skill tags, topo order + gating, mastery math incl. coverage and time decay, FSRS review with 2-day time travel, review cap/rating rules, session lifecycle). Real DB: `scripts/seed_attention.py` → 8 skills, 14 chunks, `corpus_v1` green.
