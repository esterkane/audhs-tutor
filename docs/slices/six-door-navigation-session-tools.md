# Six destinations and grouped session tools

The owner-provided usability review identifies redundant navigation and competing session controls. Primary navigation now has Home, Library, Progress, Projects, Ask and Settings. The old routes remain valid: no browser bookmark, data identifier, save scope or learning checkpoint is renamed. Library groups authoring and source access; Progress links map and exploration; Settings has an advanced-tools disclosure. The optional command palette retains secondary destinations and deduplicates URLs. Real task-review and visual-learning routes have explicit browser titles.

Session context, plan/energy settings, optional code work, alongside work and experiment links share a More session tools disclosure. Children remain mounted when it closes, preserving drafts and asynchronous recovery state. The open/closed view is remembered for that session in the browser tab. The reader/check, pause/end controls, timer actions and actual recovery remain outside. Alongside effects are inactive while the tools are closed. Further lesson AI-help/notes consolidation and broader Library/search work remain on the design checklist.
