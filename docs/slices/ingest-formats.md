# Slice: ingest-formats (Stage 3 follow-up, 2026-09-20)

**Story.** The owner drops *any* course material into a folder — Word/PowerPoint/Excel exports, ODF, EPUB, HTML, RTF, LaTeX, code repos (also zipped), every common subtitle/transcript format — and `make ingest` turns all of it into provenance-carrying chunks, with the same idempotency, dedupe and trust rules as captions and notebooks (ADR-0002, ADR-0008). Nothing is parsed by a new third-party library: Office/ODF/EPUB are zip+XML, HTML/RTF/LaTeX/code are text — all stdlib.
**In/out.** `knowledge/ingest/`: `transcripts.py` (SBV, ASS/SSA, TTML/DFXP, Whisper/YouTube-json3/generic JSON, Whisper TSV/CSV, timestamped plain text incl. Otter/Zoom "Speaker  0:12" style → cues → the caption merger, so `@mm:ss` citations work), `office.py` (DOCX headings/paragraphs/tables, PPTX slides in presentation order with titles + speaker notes, XLSX sheets as tables; ODT/ODP/ODS), `epub.py` (OPF spine order, nav skipped), `htmltext.py` (headings, paragraphs, lists, tables, `<pre>` as code; script/style/nav dropped), `rtf.py`, `latex.py` (sections → headings, verbatim → code, formatting commands unwrapped), `sourcecode.py` (30+ languages, split at top-level definitions, fenced with the language, **secrets redacted**), `structured_text.py` (rst/org/adoc headings; `.txt` is sniffed for transcripts first), `archives.py` (zip/tar[.gz|.bz2|.xz]: zip-slip guard, size/member caps, dot-folders, `node_modules`, `.env*`/key files skipped; members get `<archive>!/<member>` URIs so re-runs are no-ops), `converters.py` (macOS `textutil` for legacy `.doc`; `soffice` for `.ppt` when installed). New block kind `table`; new source types `transcript`, `document`, `book`, `html`, `code`. `GET /api/corpus/capabilities` reports formats + tool status; `scripts/ingest.py --capabilities`.
**Events.** None (knowledge-system action). Model calls made by the media slice are logged in `model_call` (see `media-transcription`).
**Mode/energy.** Not session-facing. The `/corpus` screen gains a collapsed "All supported file types" list and a readiness line so the owner knows *before* ingesting what will be skipped.
**Accessibility.** Labelled native controls; `<details>` for the long list; readiness as plain text with the exact next step, no colour-only status.
**Verified by.** `tests/test_ingest_formats.py`: one fixture per format built in-test (docx/pptx/xlsx/odt/odp/epub zips generated with `zipfile`), transcript sniffing, archive safety (traversal, dotfiles, `.env`, nested archive), secret redaction, idempotent archive re-run, capabilities route, ingest of a mixed folder end to end with `SqliteHybridRepository`.
**Open.** `.ppt/.key/.pages/.7z/.rar/.mobi/.djvu/.svg` stay unsupported with an export hint. Spreadsheets are capped at 200 rows per sheet. JSON that is neither a transcript nor a links list is reported as skipped (datasets are not learning material).
**Review fixes (code-reviewer, 2026-09-20).** Blocker: `.ts`/`.mts` were mapped to MPEG-TS *video* after the code mapping, so every TypeScript file would have gone to the transcriber — removed from `VIDEO_SUFFIXES` (`.m2ts` stays), `.mts/.cts` map to TypeScript, regression test. Majors: `redact_secrets` now redacts only literals (quoted ≥ 12 chars or bare ≥ 16 word chars not followed by `.`/`(`/`[`) with a word boundary before the key — `next_token = model.generate(...)`, `token = tokenizer.decode(ids)`, `secret = settings.SECRET_KEY` stay intact (tests); legacy Office (`.doc/.ppt/…`) left the hash shortcut because the stub could not reproduce the converted document's title; archive extraction now reports every skip except pure noise (dot/build folders); `x.tar.gz` members inherit lecture `x`, not `x.tar`; XML from zip containers goes through `xmlsafe.parse_xml` (DTD/entity declarations refused, 50 MB cap per part); converters pass resolved paths (`file:` prefix for ffmpeg). Minors: config JSON (`package.json`, `tsconfig*.json`, …) is ignored like lockfiles; `IngestRequest.language` validated (`^[a-z]{2,3}$`); generated `api-types.ts` is prettier-formatted by `make gen-api` so the diff shows only schema changes. Left as documented: `.rst/.org` heading heuristics are simple; JSON datasets are skipped, not summarised.
