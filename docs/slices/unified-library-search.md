# One Library search and contextual source inspection

The previous Library linked to several overlapping search pages; the older general search also loaded a retired project-guide manifest. Library now owns one query field with My material, Saved answers and Source passages. Personal draft notes and active lesson titles are searched through existing learner-scoped reads; answer/source lookups retain their existing bounded local APIs. Results are read-only, and opening a lesson still requires the existing explicit start/keep-current choice. Authoring, grading, histories, model routing and hosted spending are unchanged.

Legacy `/search` and `/sources` links canonicalize to Library without discarding query, passage/chunk identifiers or hash. The palette submits to Library and keeps old search/source words as discovery terms for its one Library entry. The source viewer is a focused inspection with the full citation, context, warnings and provenance. Closing, reload and browser Back/Forward preserve the query and return focus to the passage action. Hidden results stay mounted; inspection does not regenerate an answer or repeat the search. Refreshing the same query explicitly refreshes results; each failed group can retry independently while retaining marked earlier results. Query-specific keys prevent delayed older responses replacing a new query.

Recent owned drafts provide a direct return to writing. Retired guide manifests and area directories are not presented as search matches. Project/notebook edits, unsaved writing and web content are outside scope. Results are bounded and snippets shortened; long citation names are shortened only in result display, with complete provenance in inspection. A long-name browser case exposed a viewer flex-width problem, fixed by bounded wrapping while keeping Close reachable.

Verification: 824 UI tests passed; TypeScript, full ESLint and build passed. Sixteen search/navigation browser scenarios passed, including legacy URLs, open/reload/close/Back/Forward, independent refresh failure/retry with retained results, late-response protection, 200% Chromium tab zoom, mobile axe and long unbroken filenames. The full isolated upload/research/write/review/activate/read/notes/pause/resume/check/recap flow passed, extended to find its own saved draft through Library and find the active lesson again after completion. Backend APIs and persistence did not change. Databases, credentials, raw reviews and captured learner data are excluded from publication.
