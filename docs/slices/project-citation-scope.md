# Project explanation citation scope

The versioned project teaching policy now requires numbered references to come from documentation actually returned to the session. Familiar external links are not evidence merely because the model knows them. The tutor should retrieve another necessary source when possible, distinguish deductions from documented statements, and preserve the complete explanation and its qualifications.

This is prompt guidance, not a guarantee of factual correctness. Existing citation and factual guards remain enabled. Retrieval, accepted-material reuse, provider routing, spending limits and stored session history are unchanged.

## Verification

Real hosted browser journeys covered English and German isolation explanations, vector distance operators and ranking deductions, explicit no-quiz requests, and exact transcript resume. Saved answers were inspected for correctness and completeness. A separate source-gap journey rejected a fabricated PostgreSQL automatic-retry setting, explained whole-transaction retry including application decisions, and distinguished missing search evidence from a documented contradiction.

The English vector journey completed its test in 20.7 seconds and the German journey in 35 seconds. These are small end-to-end samples, not model decoding benchmarks or proof of a general latency improvement. Question and response-format repairs still occurred. German neutral-persona explanations also used unsolicited analogies; that remains outstanding. The first German attempt failed on an English-only test locator, corrected for the subsequent full pass.

The change does not qualify local models for causal explanations. Fresh complex explanations retain the owner-enabled hosted route; local generation remains limited to demonstrated reliable tasks.
