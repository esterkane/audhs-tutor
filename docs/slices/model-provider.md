# Slice: model-provider (Stage 0)

**Story.** Any LLM call in the app goes through one gateway that resolves a `TaskClass` to a registry model, respects the daily hosted budget, falls back predictably and logs a `model_call` row — so "why this model" is always answerable.
**In/out.** `models_ai/provider.py` (`TaskClass`, `Message`, `ModelSpec`, `ProviderResult`, `ModelProvider`/`EmbeddingProvider` protocols); `ollama.py` (LiteLLM chat + Instructor JSON mode, native `/api/embed`, `/api/generate` stats for benchmarks); `claude.py` (LiteLLM `anthropic/…`, Instructor TOOLS mode, `cache_control` on the first system message); `fake.py`; `routing.py` + `routing_profiles.yaml` (chain = learner override → primary → fallbacks; first `ready` wins); `budget.py` (sum of `model_call.cost_usd` since 00:00 UTC); `gateway.py` (`ModelGateway.complete`); `factory.py` (wiring from Settings).
**Events.** `degraded` (budget blocked a hosted call; context from_alias/to_alias/reason) and `invalid_output` (Instructor exhausted 2 retries; escalate one tier). Every call, success or failure, is a `model_call` row with `registry_id`, route ∈ primary|fallback|degraded, tokens, cost (local = 0 explicitly), latency.
**Cost.** Hosted cost = tokens × registry prices (`hosted-strong` = Claude Sonnet 5, `hosted-medium` = Claude Haiku 4.5), or LiteLLM's reported cost if higher.
**Verified by.** `tests/test_model_provider.py` (seed/ready detection, fallback routing, learner override, assign guards, zero local cost, priced hosted cost, budget trip → degraded, invalid output → escalation, exhaustion error).
