# Slice: language-voice-block (P9, 2026-09-20)

**Story.** Inside the language block — and only there — the learner can hold a short spoken conversation in the target language. It is practice: it is logged with a self-rating, never as competency. Assessment stays where the criteria are (listening tasks, vocabulary cards, explain-back), each with confidence before feedback.
**Backend.** `TurnRequest.conversation_lang` (ISO code): the turn runs on the **language node** (`practice.vocab_deck(lang)`), without retrieval or a checkpoint write, on `TaskClass.CHAT_FAST`, with `asked`/`explained`/`spoke` stamped `domain=language`; `TutorTurn` keeps the pedagogy base policy but swaps the task instruction for `prompts/voice/conversation.v1.md` (reply in the language, ≤ 2 spoken sentences, one easy follow-up question, at most one gentle correction, no assessment/praise, no citations since there is no source). The voice loop passes `lang` + `conversation: true`; `spoke` events carry `domain=language`. Nothing here creates `competency_evidence` or review items.
**UI.** `LanguageBlock` offers a third concrete option — "Conversation practice (DE, voice)" — only when `voice.enabled` and `voice.conversation_lang` are set (both explicit preferences). `ConversationBlock`: the `VoicePanel` in conversation mode with the note "Practice only: nothing here is graded or counted as mastery", then "How did the conversation go?" (1–5) → `practiced{domain: language, activity: conversation:<lang>, duration_min, self_rating}` via the existing practice log, or "Skip logging".
**Not in this slice.** Hosted realtime conversation (paid; no key, no authorisation), pronunciation scoring, an assessed conversation mode — an assessed variant would need a rubric item created for the exchange (explain-back over the transcript) and is a follow-up once the owner's models are installed.
**Verified by.** `tests/test_voice.py::test_conversation_turn_stays_in_the_language_block` (language node, all events `domain=language`, no retrieval trace, `chat_fast` on the local route, block checkpoint untouched). Only languages the reachable Kokoro voices speak are offered (`conversation_lang_supported`); German is not among Kokoro-82M v1's — the owner needs a different TTS voice model for DE practice (registry row, ADR). `LanguageBlock` gating has no dedicated component test (recorded).
