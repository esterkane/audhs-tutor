# G2 — Grounded Ask answers and explicit checks

Status: contract implementation; not yet connected to the Ask UI or generation.

Problem: saved-answer source checks compare corpus hashes only. An unchanged source
is not evidence that an answer's claim follows from it. Ask currently has no sources.

Implement an independently stored check against an immutable answer-text hash and
source passage hashes. Reports identify exact claim quotations and evidence passages;
unknown, contradictory and stale evidence must not become a global "verified" badge.
Model review stays distinct from independent factual verification. Failed checks
leave the original answer usable and labelled unchecked. No learning-state writes.

First bounded files: schemas/answer_checks.py, orchestrator/answer_check_binding.py,
tests/test_answer_check_binding.py. No new dependency, network provider, UI control
or automatic retrieval. Keep inherited source_registry.py untouched.

Next vertical integration: learner-owned persisted check attempts with idempotency,
local retrieval from explicitly selected sources, claim review through local gateway,
inspected reference cards and per-claim disclosures in Ask. Search/fetch must not
silently transmit private questions or source passages. Fetch failures remain visible;
free access and licensing are distinct. Curated public-tag discovery and reviewed
query controls precede optional web search. Test poisoned text, invented citations,
false arithmetic, conflict/staleness and interrupted checks before publication.

Acceptance limits: exact quotation/hash validation establishes binding only, not
semantic entailment or truth. A local model may recommend support status but cannot
make its own answer independently verified. Human-reviewed cross-area evaluation
remains required. Existing corpus does not automatically attach to free-form Ask.
