# Slice: untrusted-content-guard (Stage 3)

**Story.** A course, blog or forum text that says "ignore previous instructions" stays quoted material: it never reaches the system role, it cannot fake a section of the user message, it is flagged everywhere the owner can look, and from low-trust tiers it is not shown to the model at all (ADR-0008).
**In/out.** `knowledge/provenance.py`: patterns run on `scan_text()` (NFKC + zero-width/bidi controls stripped, so `ig​nore` and full-width letters match); new flags `authority_claim` ("note to the AI assistant", "as your developer"), `encoded_blob` (≥ 120-char base64 runs), `obfuscated` (a pattern that only appears after stripping invisibles, or ≥ 3 invisibles in clean-looking text); `exfiltration` narrowed to credential tokens so "output for token i" no longer trips it. `orchestrator/context.py`: `quarantine()` drops flagged hits below `QUARANTINE_BELOW_TRUST = 2` before the packet is built and logs `retrieved:<id>:quarantined` in `dropped` (→ `tutor_trace.dropped_json`); course-tier (2+) flagged chunks stay, escaped, with `flags=` in their header. `escape_data` (existing) neutralises `<>` and line-leading `#`, so injected `</retrieved_data>`, `<system>` and `## Output contract` become inert; `learner_answer_block` does the same for answers in the grader. `tools.retrieve` keeps `min_trust=1`, so tier 0 never leaves the index. Policy `prompts/_base/pedagogy.v1.md › Sources` now states the quoted-material rule and what `flags=` means (byte-stable prefix changed → prompt cache resets once). Ingest stores per-chunk flags (`chunk_provenance.flags_json`; Corpus screen shows counts per course/document). Session screen shows `(flagged: …)` on sources; Corpus inspector shows flags per hit.
**Events/traces.** `retrieval_trace.flagged_patterns`, `tutor_trace.dropped` (`…:quarantined`), done-event `flagged` + per-source `flagged`. No learner event: the learner did nothing.
**Mode/energy.** n/a. Pedagogy: the policy tells the tutor to mention flagged sources only "if it matters" — no alarm text in normal turns.
**Verified by.** `tests/test_untrusted_guard.py` (end-to-end through `TutorTurn` with a poisoned course chunk, a poisoned blog chunk, a zero-width-obfuscated chunk and a forum chunk: system == policy; course poison quoted + escaped + flagged, fake section and closing tag inert; web/untrusted absent from the prompt; retrieval trace flags, tutor trace quarantine list, done event; grader: learner answer cannot close its block or add a section; obfuscated / full-width / base64 / authority-claim flags; escaping idempotent) + `test_orchestrator.py::test_data_block_escapes_and_flags_poison` (trust-0 quarantined) + `test_ingest.py` (flags stored at ingest, only the forum dump flagged across 17 clean documents).
**Review fixes (pedagogy + code reviewers).** Only high-precision flags quarantine (`QUARANTINE_FLAGS`: ignore_previous, role_override, exfiltration, fake_markup, hidden_directive, authority_claim, obfuscated); `system_prompt_ref`, `fake_section`, `tool_call_injection`, `encoded_blob` stay advisory (normal in AI/programming material). Threshold is `Settings.quarantine_below_trust` (default 2), threaded through `TutorTurn`. The Session screen now discloses "N sources withheld" (no covert adaptation) and says "no course source" only when nothing was withheld; the Corpus screen defines "flagged", labels every trust select, collapses secondary tasks, lets the owner re-tier a document (`PATCH /corpus/documents/{id}`, index payload updated in place) and the inspector's "as the tutor sees it" applies the tutor floor and marks would-be-quarantined hits. Policy sentence rewritten to be literal (no "if it matters"); ADR-0008 amended with the drop rule. Tutoring hard checks after the prompt change: 4/5 (= baseline; the first, longer wording cost two citations → shortened).
**Open.** Tool results other than retrieval and learner answers (future Pyodide output) must go through the same `data_block`-style quoting when they arrive (Stage 5). Semantic injection without trigger words is not detectable by patterns; the trust tier + citation discipline is the real defence.
