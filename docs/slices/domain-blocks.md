# Slice: domain-blocks (Stage 4)

**Story.** Language, guitar and movement are whole blocks at session boundaries (ADR-0006): vocabulary cards are spaced like everything else but only ever appear in the language block; movement and guitar blocks offer two or three concrete activities, a soft timer and a one-tap rating; skipping is allowed and remembered as a pattern.
**In/out.** `kernel/practice.py`: `vocab_deck(lang)` (get-or-create `lang-<code>` skill node in the LANGUAGE domain), `add_vocab()` (idempotent `ReviewItem(item_type="vocab")` + FSRS card via `memory.ensure_item`), `decks()`, `language_due()`, `log_practice()` (`practiced` event: duration, self-rating; context domain/activity/notes; activity type movement or domain_switch), `ACTIVITIES` (2–3 options per domain). `memory.due_items(domain=…, exclude_domains=…)`: the AI/ML review and the session due count exclude language; the language block asks for `domain=language`. Planner: `Block.domain`, `PlanInput.language_due/guitar`; the domain block becomes a language block when cards are due (pref `planner.language`), else a guitar block (pref `planner.guitar`), only at energy ≥ 3; movement primers carry `domain=movement`. API: `POST /api/practice`, `GET /api/practice/activities`, `GET/POST /api/vocab`, `GET /api/review/due?domain=language` (vocab reveal = translation + example). UI: `PracticePanel` (movement/guitar: pick one, rate 1–5, notes, "Log and continue" / "Skip this block" → `block_ended reason=skipped`), `VocabPanel` (reveal → Again/Hard/Good/Easy via the normal review endpoint, quick-add), `/vocab` screen; the session runs the movement primer first when the plan starts with one and renders domain-switch blocks instead of skipping them.
**Events.** `practiced` (+ the usual `block_started`/`block_ended`; `reviewed` for vocab cards through the review endpoint).
**Mode/energy.** Domain blocks are optional and appear only at energy ≥ 3; low energy keeps the minimum-viable path.
**Accessibility.** Choice groups with labels; rating buttons are a labelled group; no timers beyond the soft wind-down.
**Verified by.** `tests/test_domain_blocks.py`: vocab cards live in the language domain and never enter the AI/ML due list, idempotent add, deck counts; planner picks language then guitar and nothing at low energy; `practiced` payload/validation; routes (add card → due in the language block only, reveal text, rate → no longer due, activities, practice log, skipped movement emits `block_ended reason=skipped`). `PracticePanel.test.tsx` (movement flow + skip; vocab reveal/rate/continue).
**Open.** Guitar activities are a fixed list (no tab/song library); vocabulary import (CSV) is not built; language blocks do not yet use the tutor for example sentences.
**Review fixes.** The movement-after block carries `domain=movement`; `replan()` validates its output; vocab quick-add is collapsed inside the language block (one task per screen).
