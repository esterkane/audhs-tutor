# Slice: media-robust (course-material stage 2, 2026-09-21)

**Story.** The observed gap: 24-bit course WAVs were handed unchanged to the STT adapter, which only reads 16-bit PCM, so every such lecture failed. Now any PCM/float WAV is normalised before transcription, the conversion is recorded as provenance, and the original bytes are never touched. The vision model's answers are cached in a bounded, versioned store so a slide that appears in several archives (or a re-run after an interruption) costs one model call, while a model or prompt change invalidates old answers and a failure is never reused.
**In/out — WAV.** `media.py`: `probe_wav()` parses the RIFF header itself (PCM, IEEE float, `WAVE_FORMAT_EXTENSIBLE` with sub-format GUID, open-ended `data` sizes from streaming writers) — the stdlib `wave` module refuses extensible/float files; `normalize_wav(src, dst)` reads 8/16/24/32-bit integer and 32/64-bit float samples **in ~10-minute blocks** (peak memory a few hundred MB whatever the length: block-wise downmix, NaN/Inf scrubbed, overlap-save polyphase resampling with `scipy.signal.resample_poly` — scipy is now declared in the `stt` group; without it the run refuses instead of resampling without a low-pass), writes 16-bit PCM to a temp file with the exact output length; the STT adapter's `read_wav_mono16k` stays 16-bit-only by design. The converter boundary is kept: `transcribe_media` probes first and normalises in-process only for PCM/float at a known depth under `MAX_WAV_BYTES` (1.5 GB of samples); anything else in a WAV container (ADPCM/µ-law, oversized) goes to ffmpeg/afconvert exactly like an mp3 when a decoder is installed, and only otherwise raises `RuntimeError(… needs ffmpeg …)` → outcome `retryable_error`. `transcribe_media` now normalises every native WAV (`decoder = "wav-normalise"`) and records `source_format` (e.g. `pcm24 48000 Hz 2ch`, `mp3 via afconvert`) on the result, the transcript cache entry, `SourceDoc.meta["transcription"]` and the `model_call` row; the duration comes from the normalised audio. The transcript cache is **model-aware**: an entry is reused only for the same `registry_id` + `model` (or when no model is available to redo it), malformed entries are misses, writes are atomic, and `--retranscribe` (`force_media`) bypasses both caches.
**In/out — vision cache.** `vision.py`: key = sha256(prepared image bytes)[:32] + MIME + registry id + model + `PROMPT_VERSION` (bump it when `PROMPT` changes); entries are JSON files under `VISION_CACHE_DIR` (`Settings.vision_cache_dir`, default `./data/vision`, wired by `runtime.default_options` into `IngestOptions.vision_cache`) holding the text, tokens, latency, `empty`, all key fields and `cache_version`. `load_vision_cached` validates every key field and the versions (a corrupt or tampered entry is a miss and gets overwritten); `save_vision_cached` writes through a private temp file and bounds the directory whenever the entry count crosses the limit and on every 50th entry (`MAX_CACHE_ENTRIES` 20 000, `MAX_CACHE_BYTES` 256 MB; least recently *used* first — a hit touches the entry; the entry just written is never evicted; stale `.tmp` files are removed). Successful answers **and explicit `NO_CONTENT` answers** are cached; a `RuntimeCallFailed` never is, and a **blank 200 reply** (an evicted model, an undecodable image) is turned into a `RuntimeCallFailed("empty response")` so it is logged, retried and never cached as "no content". `PROMPT_VERSION` covers the prompt *and* the generation options. `read_image(..., cache_dir, use_cache)` returns `meta["vision"]["cached"]`, `cache_key`, `prompt_version`; on a hit `tokens_in/out` and `latency_ms` are 0. `service._log_runtime_call` records a hit (vision *and* transcript cache alike) as a `model_call` row with `cached=True`, zero tokens and latency and `metadata.cache = hit`; `usage.cost_report` counts those rows as `cache_hits` (window and per task/provider), **not** as calls, and the Models screen says so — the audit shows the file was handled, usage is not counted twice. Provenance, flags and quarantine of the extracted text are unchanged (per document, as for any chunk).
