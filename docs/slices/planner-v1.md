# Slice: planner-v1 (Stage 2)

**Story.** A session has a visible plan of blocks sized to the learner's mode and energy, with the minimum-viable path always present, movement only before or right after new material, and no domain switch inside a block.
**In/out.** `kernel/planner.py::plan_session(PlanInput)` → `Plan{blocks[type, planned_min, node_ids, optional, reason, grasp_check_required], minimum_viable, total_min}` following the template (movement · retrieval · new material · challenge · interleaved review · domain switch · recap); energy scales lengths (60 %–120 %); low-capacity/energy 1 → retrieval + one short block + recap; preferences (`planner.*`) shape lengths, movement placement and the challenge. `validate_plan` enforces the invariants (recap last, retrieval first after optional movement, movement adjacent to new material, ≤ 90 min, ≥ 3 min per block). `can_switch_early`: leaving new material early needs a grasp check unless saving and stopping. `GET /api/plan/preview`, `POST /api/plan/blocks/start|end` (block events, refusal message when the grasp check is missing); `POST /api/sessions` stores the plan on the session. UI: `PlanStrip`, block flow in the session screen, soft timer per block.
**Events.** `block_started`, `block_ended{actual_min, switched_early, reason}`.
**Verified by.** `tests/test_stage2_kernel.py` (every mode × energy × due combo valid and deterministic; rules), `tests/test_stage2_api.py::test_plan_blocks_resume_and_map`, Stage 2 benchmark A.
