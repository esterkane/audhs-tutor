# Slice: media-transcription (Stage 3 follow-up, 2026-09-20)

**Story.** Audio and video lectures (mp3/m4a/wav/flac/ogg/opus/…, mp4/mkv/mov/webm/…) become timed, citable transcript chunks; slide images (png/jpg/webp/heic/…) become text via a local vision model. Both run through the **model registry** (ADR-0010): STT is `TaskClass.STT` → registry default `whisper-large-v3-turbo` (`mlx-community/whisper-large-v3-turbo`, runtime `mlx`, pulled by the owner with `make models args="pull whisper-large-v3-turbo"`, optional Python extra `uv sync --group stt`); OCR is `TaskClass.VISION` → `gemma3-12b` via Ollama. Nothing is downloaded at ingest time; without a ready model the file is reported as skipped with the exact next step.
**In/out.** `knowledge/ingest/media.py`: `Transcriber` protocol + `MlxWhisperTranscriber` (lazy import; audio is passed as a 16 kHz mono array so ffmpeg is not required by the model), `find_decoder()` (ffmpeg, else macOS `afconvert` for mp3/m4a/aac/mp4/mov/wav/aiff/caf/flac; ogg/opus/mkv/webm need ffmpeg), `sidecar_transcript()` (a caption/transcript next to the media wins — no transcription), transcript cache `data/transcripts/<sha256>.json` (`Settings.transcript_cache_dir`), segments → the caption merger (rolling-repeat dedupe also catches Whisper loops). `vision.py`: `ImageReader` protocol + `OllamaImageReader` (`/api/generate` with the image, temperature 0, prompt asks for verbatim text then a one-line figure description; `NO_CONTENT` → skipped), `sips` normalises heic/tiff/bmp/webp to PNG. `runtime.py`: `transcriber_for` / `image_reader_for` resolve the registry route and refuse when the artefact is missing. `service.py`: unchanged media/images are detected by content hash **before** decoding (no re-transcription), each transcription/OCR writes a `model_call` row (`task=stt|vision`, provider, latency, seconds of audio); `IngestResult.transcribed_seconds`. Knobs: `--language xx` / `IngestRequest.language` (default auto), `--no-media` / `IngestRequest.media=false`. Registry: `installed_models()` sees MLX snapshots on disk, `bench` for `stt` reports ms per 10 s of audio.
**Events.** None; observability via `model_call`. Transcribed and OCR'd text is **untrusted data** like every chunk (flags, quarantine, `data_block`), and a vision model's output is never treated as ground truth about the slide — the chunk cites the image file.
**Mode/energy.** Not session-facing; long transcriptions belong in `scripts/ingest.py`, not the HTTP form (synchronous in Phase 1).
**Accessibility.** Readiness shown as text with the next action; the `/corpus` form exposes language and the media toggle as labelled native controls.
**Verified by.** `tests/test_media_ingest.py`: fake transcriber/reader (no network, no MLX), WAV generated in-test, real `afconvert` decode on macOS (skipped elsewhere), sidecar rule, cache reuse across a trust re-decision, hash pre-check (transcriber not called twice), `--no-media`, missing-model skip reasons, `model_call` rows, registry readiness from an on-disk MLX snapshot, routing for `stt`/`vision`.
**Open.** Whisper quality on German/English mixed lectures is untested here (owner: pull the model, run one lecture, compare with the Udemy caption). Speaker diarisation is out of scope. Vision OCR needs `gemma3:12b` pulled (not yet); llama3.1 has no vision and is deliberately not a fallback.
**Review fixes (code-reviewer, 2026-09-20).** Majors: archive members now pass the same per-file gate as plain files (`_gate`: media disabled, caption-next-to-media, archives disabled) — a zip with `a.mp4` + `a.en.vtt` ingests the caption only (test); the sidecar rule accepts `.json/.txt/.tsv` only when they *parse as a transcript* (Udemy `lecture.json` metadata no longer hides a lecture) and the lecture-folder rule applies only when the folder holds exactly one media file; every vision call writes a `model_call` row, also when the model answers `NO_CONTENT`, and a failing STT/vision call raises `RuntimeCallFailed` → `model_call(ok=False, error=…)` (tests); vision records `prompt_eval_count`/`eval_count` as tokens and resolves the Ollama tag via `registry.spec_from_row`; media/images are hashed with a streamed `hashlib.file_digest` and never read into memory by the loader. Minors: `IngestOptions.force_media` / `scripts/ingest.py --retranscribe` bypasses the unchanged-hash shortcut after a model change; skip reasons name the model actually routed for `stt`/`vision` (`runtime.pull_hint`) instead of hardcoded ids; `runtime.default_options()` is the single builder used by the API and the CLI; dead `Settings.whisper_model` removed; the vision prompt states that instructions visible in the image are slide text to copy, never to follow.
**Deliberately open (owner decision).** `OllamaImageReader` calls Ollama's HTTP API from `knowledge/` because `ModelProvider.complete` has no image input; CLAUDE.md exempts only STT/TTS from the "orchestrator is the only ModelProvider caller" rule. Options: (a) extend `Message` with `images` and route vision through `OllamaProvider`, or (b) amend ADR-0008/0010 to treat ingest-time OCR like STT. Until decided, the call is logged like every other model call (registry id, tokens, latency, `ok`).
