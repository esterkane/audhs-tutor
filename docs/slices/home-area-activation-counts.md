# Home area activation counts — 2026-10-03

Home previously listed every imported knowledge area as a topic without showing whether its drafts
had been activated as lessons. Source candidates and generated drafts do not create teachable nodes.
The selected empty area therefore correctly had no next skill, but choosing it looked like choosing
a ready learning session.

The area catalogue now reports active_lessons from one skill-node read, filtering through the
existing kernel teachable rule. It performs no per-area mastery/prerequisite queries. Activated count
is not labeled ready: Home's selected /skills response remains authoritative for what can start.
Dropdown options show activated lesson counts or needs preparation before selection. A selected zero
count explains that imported sources/drafts need review/activation. Activated-but-unavailable topics
link to active lesson/prerequisite review on /map rather than prescribing another activation.
Unknown counts use neutral copy. Explicit topic never changes and no content is autoactivated.
