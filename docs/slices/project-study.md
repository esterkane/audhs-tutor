# Local project study

Generic programme/course/project-step navigation reads an optional local manifest. Explanations precede practice, hints and self-check checklists are explicit, and clear/later labels are bookmarks rather than mastery. Pause retains notes, with browser-local save/failure feedback.

Notebook reader renders cell source as text without executing outputs or uploading files. Saved notebooks may have locally supplied per-cell explanations. Imported content and acquisition tools are outside version control; production builds remove local-learning assets. Publication CI rejects tracked databases/private learning assets.

This is an initial project-study interface, not a completed curriculum acquisition system or automatic grader. Existing learning kernel and assessment flows remain authoritative.
