# Slice: course-curation (course-material stage 3, 2026-09-21)

**Story.** An imported course is a pile of documents: the instructor's captions, slides and notes, but also community notebooks, bundled software docs from downloaded repositories, link lists and decorative pages. Before a course becomes lessons the owner decides what each document *is* for that course — primary teaching material, supplemental, or excluded — and a draft is built from primary sources only, saying in its notes what it left out and why. Originals, provenance and trust never change; a role is a separate decision row.
**States.** Material: `imported` → `searchable` → `draft` → `published` (unchanged). Per document, orthogonal to those: an effective **role** = the owner's decision (`course_source` row, `decided_by: owner`) or, without one, a deterministic suggestion (`decided_by: suggested`). Draft: `draft` → `published | rejected` (unchanged). Nothing publishes or re-tiers automatically; quarantine flags are untouched.
**In/out.** `kernel/curriculum.py`: `suggest_role(doc)` — literal rules only: `external-links.json` → supplemental (a list of links references material), an archive member (`!/` in the uri) → supplemental (bundled repository/software docs/notebook), an **unnumbered** code file or notebook → supplemental (a numbered one is a lecture slot the instructor filled), everything else primary; `source_roles`, `course_sources` (every document of a course with role, reason, decided_by and its unique latest-version passage count, in section/lecture order), `set_source_role` (upsert, refuses a document of another course), `reset_source_role`. `section_material` now takes **primary** documents only and lists the rest in `SectionMaterial.left_out`; `unique_chunks` is the coverage (duplicates via `Chunk.duplicate_of` count once — a second document with the same text has no unique passages and no lecture slot). `create_draft` refuses a section without primary material with a message that says how many documents are supplemental/excluded, and adds `info` notes: "built on N primary document(s), M unique passages" and one "not used (role, decided_by): 'title' — reason" per left-out document. `Problem.level` gains `info`. Table `course_source{course, document_id (unique), role, reason, decided_by, decided_at}` (migration `c8e2f1a9b4d0`). **API**: `GET /api/curriculum/sources?course=` (documents + role counts), `PUT /api/curriculum/sources/{document_id}?course=` `{role, reason}`, `DELETE …` (back to the suggestion). **UI** (Curriculum › Sources of *course*): every document with section, type, passages, the role as a native select, the suggestion reason, "use suggestion"; the role counts; the draft's info notes appear with the problems. **Script** `scripts/draft_course.py --course NAME [--section] [--snapshot|--live] [--json]`: by default a dry run on a private online-backup **snapshot** of the configured DB — lists roles, drafts every section deterministically, checks every citation resolves, prints errors/warnings/notes; `--live` writes drafts into the configured DB (still drafts). No model is called; the model path of the Curriculum screen is unchanged (proposals flagged, reviewed like everything else).
**Events.** None (content management). Drafting writes no `learning_event`, `competency_*` or `memory_state` rows (tested).
**Mode/energy.** Not session-facing.
**Accessibility.** Roles are a labelled native `<select>` per document; reasons are literal text; counts are text.
**Verified by.** `tests/test_course_curation.py` (7): suggestions per document kind, owner decision remembered and reversible, provenance untouched, cross-course refusal (set and reset); a draft built with an excluded page and suggested-supplemental notebook/links: no skill from them, every cited passage resolves to a primary document of the course, the notebook's injected sentence reaches no item, `left_out` names all three with reasons, duplicate text yields one lecture's passages, seeded learning progress (a skill with evidence, its refreshed `competency_state`, an FSRS card) unchanged by drafting and by editing, material status stays `draft`, the selection notes survive an edit; a section with everything excluded is refused with the review hint; the routes (list, counts, put, 422 on a bad role, 404, delete); the **model path** (`use_model` with a ready fake route): the prompt sent to the provider contains primary excerpts only — the injected notebook sentence, the excluded page's text and the supplemental titles never reach it — the draft carries the same selection notes, an edit over `PUT` keeps them, a client that drops `payload.selection` loses them (said, not hidden), and all-excluded is refused with the same message; the archive route sets one decision for every member and 404s for an unknown archive. Existing curriculum tests updated for the `info` level (`test_curriculum.py`, 10 pass; 291 backend, 42 frontend in total). `make migrate-check` applied `c8e2f1a9b4d0` to a snapshot of `data/dev.db`. Dry run on a snapshot of the live DB (`scripts/draft_course.py`, two courses; numbers in HANDOFF): the first rule marked every member of a course delivered as one project bundle supplemental and refused the draft — hence the rule "an archive that is a section's only material is primary" (tested); the transformer course splits 26 primary / 17 suggested supplemental and drafts per section with every citation resolving.
**Pedagogy review (2026-09-21, applied).** The draft's `info` notes are now rendered in the editor ("What this draft is built on") and counted in the drafts list; the built-on note says "built on X of N primary document(s); C of M unique passages cited" and a **warning** names the documents beyond the 30-skill cap; a primary document without unique passages (a duplicate) is listed as not used with that reason and shown as "no unique passages" in the Sources panel; role labels say "not used for lessons; still searchable by the tutor" (roles never filter retrieval); the panel note lists all four rules literally and says supplemental and excluded are treated the same today; the fallback reason reads "no rule matched: treated as lecture material until you change it"; an owner choice without a reason renders as such; the refusal names section, counts and where to go; the editor header counts skills without success criteria/exercises and the publish button says how many warnings remain; the script prints truncation notices and the open questions.
**Code review (2026-09-21, applied).** Blocker: the notes were recomputed only at creation and vanished on the first edit — the selection is now **part of the payload** (`payload.selection`: `built_on`, `beyond_cap`, `cited_passages`, `unique_passages`, `left_out`, written by `selection_summary(mat)`) and `create_draft`/`update_draft`/`publish_draft` derive the notes from it with `selection_problems(payload["selection"])`; the JSON editor shows it, so an owner who deletes it removes the notes knowingly. Majors: the model path (`drafting.draft_with_model`) shares the refusal (`no_primary_message`) and the selection, with a test that excluded/supplemental text never reaches the provider prompt; `scripts/draft_course.py` opens the source read-only (`mode=ro`), keeps the snapshot in a `TemporaryDirectory` that is deleted after the run, and `--live` skips sections that already have an open draft; the duplicate assertions are now literal (one Softmax lecture, the copy in `left_out` with another id, `unique_chunks` equals the sum of lecture passages); "plain material" for the archive rule means a non-archive document that is itself suggested primary (a lone `external-links.json` next to a bundle no longer demotes the bundle); `PUT /api/curriculum/sources-archive?course=` `{archive, role, reason}` decides for every member of one archive at once. Minors: `reset_source_role` refuses a document of another course; the `course` column is documented; the Sources panel shows a load error; the frontend test covers the DELETE and the "no reason recorded" rendering.
**Open pedagogy / coverage questions (for the owner).** The deterministic draft invents no success criteria or exercises (warnings by design — publishing over them puts nodes on the map without a worked example). Numbered notebooks count as lectures (right for instructor notebooks, wrong for numbered community bundles); an **unnumbered instructor** notebook or code file is demoted to supplemental (deflation), while unnumbered non-code documents stay primary — decide per course in the Sources panel. The archive-only rule turns every bundled file (READMEs, licences, vendored docs) into lesson slots; the Forward-Deployed-Engineer dry run shows what that yields (30 skills, no cloze, 30 errors). Duplicated lecture text collapses to one slot (now surfaced). Supplemental sources are not cited as further reading yet. Roles do not filter retrieval: an excluded page stays searchable by the tutor.
