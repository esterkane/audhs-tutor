# Slice: session-screen (Stage 1)

**Story.** Home → one single-task session screen (learn, then check yourself) → review → confidence-rated recap. The learner chooses state mode and energy; the parking lot is always one click away.
**In/out.** `frontend/src/routes/Home.tsx` (mode / energy / questioning style as concrete choices; low energy + due reviews → review first), `Session.tsx` (Explain / Hint / Recap → streamed answer with sources → "Which next?": Check yourself, Show it differently (analogy/derivation/code/worked example), full solution behind an explicit disclosure), `Review.tsx` (show answer before rating; cap shown honestly; "Stop here" always available), `Recap.tsx` (energy after + recall self-rating + one line), `components/ParkingLotButton.tsx` (fixed, Radix dialog, Enter to park), `features/session/SoftTimer.tsx` (wind-down prompt: save & stop / 5 more minutes / finish block; never a cut-off). State in `stores/mode.ts` (Zustand, persisted; only setters change it). API types generated by `make gen-api` (`src/lib/api-types.ts`); SSE consumed by `lib/api.ts::streamTurn`.
**Accessibility.** Real buttons with `aria-pressed`, labelled fields, `aria-live` on the streamed answer, 3px focus ring, `prefers-reduced-motion` respected, no autoplay, no streaks.
**Verified by.** `pnpm vitest run` (store, parking lot in two interactions, Home choices → review-first path, review reveal-before-rate + cap, SSE parser); `tsc -b`, eslint (react-hooks purity) green.
