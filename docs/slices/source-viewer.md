# Slice: source-viewer (P4, 2026-09-20)

**Story.** A citation `[course › section › lecture @mm:ss]` under a tutor answer opens the exact passage: the cited text with its neighbours, the document, a timestamp for media, and an open link only when the server allows it (http(s), or a file under `INGEST_ROOTS`). If the chunk is gone, the citation is shown as the fallback excerpt. "Report this source as wrong" (and "Report this explanation" under the answer) keeps a note next to the evidence — nothing is rewritten.
**In/out.** `GET /api/curriculum/chunks/{chunk_id}` → `ChunkOut` (text, prev/next, provenance via `kernel/curriculum.passage`; `open_url` = http(s) as-is, or the app's guarded `GET /api/curriculum/chunks/{id}/file` (a `FileResponse`, only for a **plain file under the ingest roots** — `open_target` refuses empty paths, URLs, archive members, directories and anything outside the roots) with `#t=<seconds>` for media so the browser seeks; otherwise `null` and the path is shown), 404 when missing. `POST /api/curriculum/reports` (`kind ∈ wrong_source|wrong_explanation|wrong_grading|other`, optional turn/chunk/skill, note ≤ 2000) → `content_report` rows, `GET …/reports?status=`, `POST …/reports/{id}/resolve`. UI: `SourceViewer` inline region from the sources list on the session screen (keyed by chunk, scoped to the turn it was opened from); report affordances on sources and on the answer, each scoped to **its** turn (a new answer gets a fresh affordance).
**Events.** None; reports are rows (a later slice can surface them on the corpus screen).
**Accessibility.** `role=region` with a label (an inline disclosure, not a modal), Close button, blockquote for the passage, links open in a new tab with `rel=noreferrer`; the fallback and report states are plain text.
**Verified by.** `tests/test_curriculum.py::test_reject_and_routes` (chunk with citation, file endpoint serves the seed file, empty path → no link + 404, missing chunk 404, report create/list/resolve, invalid kind 422), `::test_open_target_guards` (empty / URL / archive member / outside roots / directory / media fragment); `SourceViewer.test.tsx` (passage, neighbours, timestamp, link, report, fallback). The session-screen wiring (open a source, report) is exercised by hand in the browser pane; `Session.test.tsx` covers block transitions only.

Recorded: no page fragment for PDFs (page numbers are not tracked at ingest); no cap on reports per turn/chunk.
