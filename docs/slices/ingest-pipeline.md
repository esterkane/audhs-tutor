# Slice: ingest-pipeline (Stage 3)

**Story.** The owner points the app at a Udemy export (or any folder of captions, notebooks, PDFs, markdown, text) and gets a provenance-carrying, deduplicated, chunked corpus in SQLite and the Qdrant index — re-runnable at any time without duplicates (ADR-0002, ADR-0008).
**In/out.** `knowledge/ingest/`: `types.py` (`SourceDoc` / `Block` / `ChunkDraft`), `loaders.py` (suffix dispatch; course/section/lecture + numbers from `<root>/<Course>/<NN - Section>/<NNN - Lecture>.ext`; one caption language per lecture), `captions.py` (VTT + SRT cues, tag/noise removal, rolling-caption dedupe, time-windowed paragraphs with `t_start`/`t_end`), `notebook.py` (markdown cells → prose with headings, code cells → fenced code + short outputs, pip/magic lines dropped), `pdf.py` (page blocks via optional `pypdf`, lazy import → `PdfSupportMissing`), `markdown.py` (front matter + `## heading {skill: slug}` sections), `normalize.py` (NFKC, zero-width stripping, `norm_hash`), `chunker.py` (heading = concept boundary, sentence packing to ~300 tokens, code fences kept whole, `title › heading` prefix), `service.py` (`ingest_source` / `ingest_file` / `ingest_path` / `forget_document`; idempotent by content hash → new `document_version` only on change; chunk-level dedupe by `chunk.norm_hash` within a course; instruction-pattern flags stored on `chunk_provenance.flags_json`; incremental index upsert + old-version removal; trust re-decision without a new version). `scripts/ingest.py --src PATH [--course] [--trust 0-3] [--type] [--no-index] [--json]`; `make ingest src=…`. API `GET /api/corpus/stats`, `GET /api/corpus/documents?course=`, `POST /api/corpus/ingest`, `DELETE /api/corpus/documents/{id}`. UI `/corpus`: course overview with flags, document table with Remove, ingest form (trust chosen by the owner).
**Events.** None — ingest is a knowledge-system action, not a learner event; `document_version.ingested_at` and `index_state` record it. Trust is never read from a file.
**Mode/energy.** Not session-facing. The screen is single-task and text-only; long ingests run synchronously (Phase 1, local machine).
**Accessibility.** Native form controls with labels, `role=status` summaries, `role=alert` errors, table with caption; no motion.
**Samples.** `seeds/courses/` = five small courses in VTT / SRT / ipynb / markdown / text (Transformers from Scratch, Practical Fine-Tuning, PyTorch Fundamentals, LLM Evaluation, Optimization Basics); `seeds/untrusted/` = a forum dump with an injection, to be ingested at trust 0.
**Verified by.** `tests/test_ingest.py`: timestamps, rolling dedupe, time windows, normalisation, notebook cells, chunker invariants (heading boundary, no mid-sentence cut, code whole, ordinals), Udemy layout provenance, 17-document sample ingest idempotent + indexed, changed file → version 2 + index swap, course-scoped dedupe, trust from caller only, trust re-decision, forget, PDF (skipped without `pypdf`, passes with `uv run --with pypdf`), corpus routes. `Corpus.test.tsx`.
**Review fixes (code-reviewer, same day).** Index written *before* the SQLite commit (a failed upsert rolls the version back and is reported per file; new chunks upserted before old ones deleted, so retries are safe); idempotency compares against the latest version only and a *reverted* file re-promotes its older version (`reverted=True`); duplicates are stored with `chunk.duplicate_of` (system of record keeps everything) and never indexed — `forget_document` promotes duplicates so text never disappears; course-less documents dedupe only against each other; front matter (`uri`, `course`, `source_type`) is honoured only for owner-authored seeds (`trust_front_matter`), never for course exports; `source_type` overrides relabel but never widen the suffix gate; the ingest API only reads under `Settings.ingest_roots` (default `~`) and never dot-folders; single-file ingests take the root three levels up; `_update_trust` uses `update_payload` (no re-embedding); migration backfills `norm_hash` + flags on pre-Stage-3 chunks; stats count flagged chunks with `case()` (SQLite `sum(bool)` collapses to 1). Router is thin again (`knowledge/corpus_stats.py`).
**Udemy resources exports.** `udemy_manifest.py`: `<Course--hash>/manifest.json` (version 2) maps `folder/filename` → clean `courseTitle` / `sectionTitle` ("Abschnitt 24: …") / `lectureTitle` ("118. …") / `label`; provenance prefers the manifest, then the folder names (`Section N - …`, `Lecture N-M - K. …`), then the plain `<NN - Section>/<NNN - Lecture>.ext` layout. Resource files under a lecture get `lecture › resource` chunk prefixes. Known-but-unsupported types (`.docx`, `.pptx`, …) are listed as skipped with a hint. `scripts/ingest.py --rescan-flags` recomputes stored flags after a pattern change.
**Open.** Ingest over HTTP is synchronous (fine for one course; a 200-course export should go through `scripts/ingest.py`). Trust re-decisions are applied but not audited beyond `chunk_provenance`. `pypdf` is not in `pyproject.toml` (dependency not listed in ARCHITECTURE — owner to approve `uv add pypdf`); PPTX/DOCX/ODF/EPUB and the rest are now parsed with the stdlib — see `ingest-formats.md` and `media-transcription.md` (2026-09-20).
