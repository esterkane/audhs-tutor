# Slice: tutor-turn (Stage 1)

**Story.** The learner asks (or presses Explain/Hint/Recap) and gets a short, grounded, cited answer streamed token by token; the system records why it said what it said.
**In/out.** `POST /api/tutor/stream` (SSE: `meta`, `token`*, `done` | `error`) and `POST /api/tutor/turn` (buffered) with `TurnRequest{session_id, text, skill_id?, action ∈ auto|explain|hint|summarize|full_solution, representation?}`. `orchestrator/tutor.py::TutorTurn.run`: session → skill (request, checkpoint, or `next_skill`) → `actions.choose_action` (hint ladder 1→3 persisted in the checkpoint; full solution only on explicit request/button) → skill-filtered retrieval widened when thin → ContextPacket → `ModelGateway.stream` (`explain_simple` / `hint` / `summarize` TaskClass, per-action token caps) → `retrieval_trace` + `tutor_trace` (+ `model_call` via the gateway) → `asked`/`explained` events → checkpoint. Sources = top-3 retrieved chunks with `[course › section › lecture]` citations, returned in `done` and shown by the UI; "no course source for this" when empty.
**Mode/energy.** `questioning_style` comes from `session.socratic`; the packet carries mode/energy; nothing switches silently.
**Prompts.** `prompts/tutor/{explain,hint,full_solution,summarize}.v1.md` on top of `prompts/_base/pedagogy.v1.md` (hard limits on sentences, plain prose, citation format).
**Verified by.** `tests/test_orchestrator.py` (traces/events/checkpoint, hint ladder, ended session), `tests/test_api.py` (SSE + buffered over HTTP). Live: two real turns on llama3.1:8b with Qdrant citations (13.7 s / 9.3 s).
