# Slice: qdrant-repo (Stage 0)

**Story.** Retrieval returns provenance-carrying, trust-filtered, hybrid-ranked chunks from Qdrant, and the same interface works offline for tests (ADR-0002, ADR-0008).
**In/out.** `knowledge/repository.py` (`ChunkRecord`, `SearchFilters`, `ScoredChunk`, `SearchResult`, `RetrievalRepository` protocol, `rrf()`); `knowledge/provenance.py` (`Provenance.citation()` → `[course › section › lecture @mm:ss]`, `TrustTier`, `flag_instruction_patterns()`); `knowledge/qdrant_hybrid.py` (collection `corpus_v<embedding_version>`, named vectors `dense` (Ollama embed) + `sparse` (fastembed BM25, IDF modifier), server-side RRF via the Query API, payload indexes for course/section/lecture/source_type/skill_ids/document_id/trust_tier, INT8 scalar quantization, on-disk vectors, one batched request returning fused + dense + sparse scores for the trace); `knowledge/sqlite_hybrid.py` (FTS5 + sqlite-vec or numpy cosine + Python RRF; tests/offline); `scripts/reindex.py` (SQLite → Qdrant, updates `index_state`).
**Traces.** Every search returns a `RetrievalTraceRecord` (query, filters, bm25/vector/fused scores, chunk ids, flagged patterns, latency); the orchestrator writes it with `write_retrieval_trace`.
**Security.** Instruction-like text in a chunk is flagged on the hit and the trace, never removed silently and never obeyed.
**Verified by.** `tests/test_knowledge.py` (citation, flags, RRF, SQLite adapter: exact-term hit, course/trust/skill filters, poisoned chunk flagged, reindex/delete) + `integration` test against the local Qdrant with a throwaway collection.
