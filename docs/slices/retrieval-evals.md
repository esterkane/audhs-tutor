# Slice: retrieval-evals (Stage 3)

**Story.** Before trusting the tutor's citations at corpus scale, the owner can measure retrieval itself: does the lecture that answers a question land in the top k, how high, and is it citable — and re-run that after every chunking, embedding or reranker change.
**In/out.** `app/evals/retrieval.py`: labels name *where* the answer lives (`course` + `lecture`, optional `contains` phrase; ids change on re-ingest, lectures do not); `evaluate(repo, queries, k)` → `RetrievalReport` (recall@k, recall@4, recall@1, MRR, citation coverage = share of top-k hits that carry course+lecture/path and trust ≥ 1, latency p50/p95, per-query hits + misses); `compare()` → deltas vs a baseline. `evals/retrieval/queries.yaml`: 32 labelled queries over `seeds/courses` (paraphrase / exact-term / filter tags). `scripts/eval_retrieval.py [--k] [--db] [--embedding-version] [--min-recall 0.8] [--baseline]` (`make eval-retrieval args=…`) runs against any SQLite + Qdrant pair, writes `evals/results/retrieval_latest.json`, exits 1 below the threshold or on a > 0.05 recall regression. Baseline committed as `evals/results/retrieval_baseline.json`.
**Events/traces.** None (dev tooling). The eval uses the production repository, so every query also leaves the normal `RetrievalTraceRecord` in memory; nothing is written to learner tables.
**Mode/energy.** n/a. No UI: evals are executable scripts by owner preference (same as `run_evals.py`).
**Verified by.** `tests/test_retrieval_evals.py`: normalised label matching + phrase check, citability (trust 0 is not citable), recall/RR/percentiles, report + deltas over a canned repository (filters passed through), and a label-integrity test that fails the suite if any label points at a lecture or phrase that does not exist in the sample courses.
**Measured 2026-09-19** (dev corpus: attention notes + 5 sample courses + forum dump, 49 chunks, `corpus_v1`, nomic-embed-text + BM25, no reranker): recall@8 **1.000**, recall@4 1.000, recall@1 0.812, MRR 0.896, citation coverage 0.996, p50 27 ms / p95 37 ms. The corpus is small; the Stage 3 benchmark re-measures on an isolated collection and the numbers matter once real Udemy courses are in.
