## Acceptance criteria per stage (condensed from the prompt pack; the pack is authoritative)
- **P1** (implemented 2026-09-20; see the four slice docs): server-authoritative block/phase transition contract, idempotent on retry/double-click; exactly one `block_started`/`block_ended` per completed block; movement/domain blocks → `practice`; review submits `confidence_pre` and resets per card; timer keyed by block identity/start time with documented +5 min / replan semantics; teaching selection restricted to eligible curriculum nodes (vocab decks stay in language practice). Journeys: full plan with reload at every boundary, low-capacity review→recap, two-card confidence, double-click, stop/resume, replan/undo, mastered AI graph + unmastered vocab deck. Browser coverage only with an approved tool (Playwright is *not* yet approved — dependency decision to record).
- **P2**: estimand per metric; aggregation at the assigned unit (or justified repeated-observation method); unit *and* event counts shown; binary-outcome intervals; no direction with inadequate independent evidence; arm fidelity (intended vs applied mode/model); active vs elapsed time; deterministic fixtures for duplicate events, sparse all-success, delayed outcomes after Stop; analysis versioned; pedagogy review of wording.
- **P3**: card identity = language + meaning + direction with an update policy and schedule-preserving migration; CSV preview → edit → confirm; idempotent, limited, atomic/recoverable imports with counts; reversed cards only when selected; donor `lernapp/backend/app/services/vocab_import.py` provenance recorded (commit hash); no private glossary imported during development.
- **P4**: statuses imported / searchable / draft / published; reviewable draft (skills, prerequisites, LearningObjects, objectives, exercises/rubrics, success criteria) with validation and versioned publish; deterministic path without a model; goal selection + "why this skill" + duration preview; Home prioritises Resume / short review / goal; citations open the exact passage/page/time in a bounded viewer with excerpt fallback; report-incorrect-source action.
- **P5**: versioned backup manifest (SQLite snapshot, shared curriculum, source references, config, integrity metadata; secrets/models excluded), restore into an *empty* target with strict validation and rollback; round-trip tests; CI (lint/types/unit, locked deps, no private data or keys), migration-upgrade test from a previous schema with data.
- **P6**: provider-reported usage incl. streaming final usage; reported/estimated/unknown states; per-attempt logging with correlation ids; concurrency-safe budget reservation/reconciliation; cost view; fake-provider tests; no new hosted TaskClass without an ADR.
- **P7**: audio + WebVTT fixture → bounded clips + one comprehension task at a time; playback only on user action; saved answers, confidence before feedback, evidence + delayed item; donor `lernapp-updates` `services/media_lessons.py` provenance.
- **P8**: one Pyodide-backed exercise with starter code, deterministic checks, hint-first help, explicit submit; timeout/output limits; evidence + delayed transfer item.
- **P9**: readiness → explicit install → verify → test → activate; capture/VAD/STT/streaming LLM/TTS with interruption; language voice block; 20-turn latency benchmark only with installed approved resources (target median ≤ 2 s to first audio) — otherwise the gate stays pending.

## Dependency decisions recorded

**Update 2026-09-21:** Owner accepted ADR-0011–0013. Those decisions supersede the historical pending decisions below. Implementation sequence: Playwright journeys → CodeMirror editor → encrypted backups → pinned local Pyodide. Approval does not mark these slices complete. Existing backups remain unencrypted; the real voice benchmark remains pending.

- **Playwright (browser journey tests)** — not in ARCHITECTURE.md; not added in P1. The P1 journeys are covered by API-level tests (`tests/test_session_transitions.py`, reload = `GET /sessions/current` at each boundary) plus component tests with mocked fetch, and were walked once by hand in the desktop browser pane (start card → movement → skip → review survives a reload → continue → teach → resume shows the phase → recap closes the block). Owner decision for P5's CI: approve `@playwright/test` (dev dependency, browsers downloaded on demand) or keep API + component coverage.
- **cryptography (encrypted backups)** — not in ARCHITECTURE.md; not added in P5. Backups are integrity-checked (sha256 manifest) but **not encrypted**; the manifest and CLI say so (`encryption: none`). Owner decision: approve `cryptography` (scrypt-derived key + Fernet, as the donor does) via `/adr`, or keep archives on encrypted volumes.
- **Corpus text in backups (policy)** — `make backup` defaults to scope `learner` (no `chunk`/`chunk_provenance`/`index_state`; documents referenced for re-ingest). `scope=full` exists for the owner's private reinstall and includes purchased course text. Owner decision: keep `learner` as the default (current) or make `full` the default with an ADR-0008 sentence.
- **Pyodide (P8)** — the binding stack lists Pyodide; it is loaded at runtime from `cdn.jsdelivr.net/pyodide/v0.27.8` inside a Web Worker (no npm package, no bundled wasm). Policy: runtime + numpy fetched once, then network APIs removed from the worker; in-memory FS; 10 s timeout by worker termination; 20 000-char output cap. Owner decision: keep the CDN load (needs network on first run) or vendor the runtime (~10 MB in `frontend/public/`).
- **CodeMirror (P8)** — `@codemirror/state`/`view` are declared but a usable Python editor needs `@codemirror/lang-python` and `@codemirror/commands` (not declared). P8 ships an accessible `<textarea>` editor. Owner decision: add the two packages (then swap the editor) or drop the declared CodeMirror packages.
- **Voice stack (P9)** — STT = registry MLX Whisper (`whisper-large-v3-turbo`, optional `stt` group), TTS = Kokoro-82M as a persistent server the owner starts (`KOKORO_URL`), VAD = energy detector with optional Silero ONNX (`silero-vad` registry row, uses the already-present `onnxruntime`). Not adopted: the donor's faster-whisper/Piper. Not added: `python-multipart` (test recordings are sent as a raw WAV body), `sounddevice` (only the spike's `--mic` needs it — optional, owner). ADR-0001 wording "MLX only for STT/TTS" vs "Kokoro server": owner may amend to "MLX Whisper for STT, Kokoro server for TTS".
- **mlx-whisper** — optional dependency group `stt` in `backend/pyproject.toml` (not installed by default); pulled model + `uv sync --group stt` are owner actions.
