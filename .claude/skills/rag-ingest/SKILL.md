# Knowledge system (ADR-0002, ADR-0008)

Pipeline (`backend/app/knowledge/ingest/`): discover → extract → normalise → deduplicate (content hash per document version) → segment by lecture/section with timestamps → semantic chunk (300–500 tokens, lecture-level header prepended) → `chunk` + `chunk_provenance` in SQLite → dense embedding (`embed` TaskClass) + sparse (fastembed BM25/SPLADE) → Qdrant upsert with payload = provenance + `course/section/lecture/t_start/t_end/type/trust_tier/skill_ids`.

Provenance on every chunk (`chunk_provenance`): `source_id, path, source_type, trust_tier, course, section, lecture, ingested_at, flags_json`; `document_version` carries `content_hash, version, publication_date`. `source_type ∈` `udemy_caption | transcript | slides | notebook | pdf | markdown | text | document | book | html | code | audio | video | image | manual` (`knowledge/ingest/types.py`). `trust_tier` is an integer **0–3**: 0 untrusted (web dumps), 1 web, 2 purchased course, 3 owner-verified; decided by the caller, never read from the file (ADR-0008).

Retrieval (`knowledge/qdrant_hybrid.py` implements `RetrievalRepository`): Qdrant Query API prefetch dense top-N + sparse top-N → server-side RRF fusion with payload filters applied *inside* the search → optional local cross-encoder rerank → trust/provenance filter → `ScoredChunk[]` with all scores kept for `retrieval_trace`. k=8 default. Collections `corpus_v<embedding_version>`; scalar quantization + on-disk vectors on by default.

Guards: chunks are never inserted into the system role; `context.data_block()` wraps them with provenance headers and escapes; instruction-like patterns are flagged at ingest (`knowledge/provenance.py`, stored in `flags_json`) and on the trace; flagged chunks below `Settings.quarantine_below_trust` never reach the tutor. `backend/tests/test_untrusted_guard.py` must pass.

Rules: idempotent by content hash (unchanged → no-op, changed → new `document_version`, reverted → older version re-promoted); a caption/transcript next to a media file wins, otherwise audio/video is transcribed through the registry STT model (`TaskClass.STT`, `knowledge/ingest/media.py`, `source_type=audio|video`, cached under `data/transcripts/`); slide images through the registry vision model (`TaskClass.VISION`); notebooks split by cell; slides one block per slide (+notes); every format is parsed with the stdlib (`office.py`, `epub.py`, `htmltext.py`, …) — see `docs/slices/ingest-formats.md`; switching embedding model → new collection `corpus_v<N>`, `scripts/reindex.py` rebuilds it from SQLite. Corpus is for personal study only — no export/share features for corpus content. **Policy (P5):** a *private* backup of the owner's own installation is not "sharing". `make backup` defaults to scope `learner` (no corpus text; documents referenced by path + hash for re-ingest); `scope=full` includes purchased course text for the owner's private reinstall only and the CLI says so. Whether `full` may become the default is still the owner's call (`docs/IMPROVEMENT-PLAN.md`).

`SqliteHybridRepository` (FTS5 + sqlite-vec) implements the same interface for tests and offline fallback; never the production path.

CLI: `make ingest src=<dir>` → `scripts/ingest.py --src PATH [--course NAME] [--trust 0-3] [--type TYPE] [--no-index] [--json] [--language xx] [--no-media] [--capabilities] [--rescan-flags]` (no dry-run/force: idempotency makes re-runs safe). API: `GET /api/corpus/{stats,documents,capabilities}`, `POST /api/corpus/{ingest,search}`, `PATCH|DELETE /api/corpus/documents/{id}`; the API only reads under `INGEST_ROOTS`. Retrieval evals: `make eval-retrieval` → `scripts/eval_retrieval.py` (recall@k/MRR on `evals/retrieval/queries.yaml`, baseline `evals/results/retrieval_baseline.json`).
